# Projeto AMO (Arcade Machine Object)

## Sobre

O projeto faz parte do desenvolvimento da matéria "Linguagem de programação 2" e tem como objetivo exercitar os conhecimentos sobre o desenvolvimento de interfaces gráficas em java

### Ferramentas utilizadas

VS Code e Java nativo

## Instalação e execução do projeto

Basta clonar/baixar o respositório e abrí-lo em uma IDE ou editor de texto de sua preferência. Recomenda-se utilizar o VS Code para o projeto, pois o repositório já
possui a configuração necessária para execução.
